# Real-Time Systems Capstone: Spacecraft Telemetry Node

## Overview
This repository contains my final integration capstone for Real-Time Systems. It models a real-time flight computer onboard a spacecraft, built on the ESP32 FreeRTOS architecture. 

**View the full project portfolio, system architecture diagram, and WCET evidence here:**

## Deliverables Included
* **Source Code:** Contains the multi-tiered Rate Monotonic Scheduling (RMS) load and fault injection logic.
* **Demonstration:** An embedded walkthrough of the system degrading gracefully under a simulated command flood.
* **Documentation:** Task timing tables, hardware interrupt latency logs, and hazard mitigation mapped to aerospace standards (DO-178C and MISRA C).
