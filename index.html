Spacecraft Ground Command Telemetry Node

Project Overview

This system models a real-time flight computer onboard a spacecraft, built on the ESP32 RTOS architecture. The system is responsible for executing periodic background telemetry tasks (simulating sensor data processing, signal filtering, and data encryption) while maintaining strict responsiveness to asynchronous, high-priority ground commands.

The primary objective of this architecture is measuring and optimizing Interrupt Service Routine (ISR) latency. Ground commands are triggered via a hardware interrupt (GPIO 18), which utilizes both binary semaphores and direct task notifications to wake high-priority response tasks. The system is stressed under a multi-tiered Rate Monotonic Scheduling (RMS) load to demonstrate predictable execution and guaranteed deadlines even under heavy CPU contention.

Hazard Analysis & Mitigation

Hazard / Fault System Impact Mitigation Strategy
Switch Bouncing / Signal Noise Spurious ISR triggers causing high-priority task starvation. Software debounce implemented; edges within DEBOUNCE_US (200µs) are dropped.
Ground Command Flood (Induced Fault) Overwhelms scheduler, causing telemetry tasks to miss deadlines. Degradation Mode: System detects rapid press count (>5) and gracefully throttles processing, prioritizing safe state over standard telemetry.
